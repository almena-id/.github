# `.github` (organization)

This directory holds **GitHub-facing metadata** for the **Almena Network** organization: narrative shown on the org profile and, over time, shared templates or policies consistent with [organization repository conventions](https://docs.github.com/en/organizations/collaborating-with-groups-in-your-organization/customizing-your-organizations-profile).

| Path | Purpose |
|------|---------|
| [`profile/README.md`](profile/README.md) | **Organization profile** README: what the platform is and how independent **product repositories** relate. It must describe each repo on its own—not an aggregate checkout or hub layout. |

For **workflows**, **issue templates**, or **CODEOWNERS**, add them in each **product repository** according to that repo’s CI and governance conventions.
